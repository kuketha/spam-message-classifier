# Spam Message Classifier — VS Code / Jupyter / Streamlit

A complete ML project: train a spam classifier in a Jupyter notebook inside VS Code,
then serve live predictions with a Streamlit web app.

## Files
- `mail_data.csv` — dataset (Category: ham/spam, Message: text)
- `spam_classifier.ipynb` — notebook: EDA → train 4 models → pick the best → save it
- `app.py` — Streamlit app that loads the saved model and predicts on new text
- `spam_model.pkl`, `tfidf_vectorizer.pkl` — saved trained model + vectorizer (already generated by running the notebook once)
- `requirements.txt` — Python dependencies

## Step 1 — Open the project in VS Code
1. Put all these files in one folder, e.g. `spam_project/`.
2. Open that folder in VS Code: `File → Open Folder...`

## Step 2 — Set up a Python environment
Open a terminal in VS Code (`` Ctrl+` ``) and run:
```bash
python -m venv venv
# Windows: venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
```

## Step 3 — Run the Jupyter notebook in VS Code
1. Install the **Jupyter** and **Python** extensions in VS Code (Extensions panel, if not already installed).
2. Open `spam_classifier.ipynb`.
3. In the top-right of the notebook, click **Select Kernel** → choose the `venv` Python environment you just created.
4. Click **Run All** (or run cells one by one with `Shift+Enter`).
5. The notebook will:
   - Load and explore `mail_data.csv`
   - Convert text to TF-IDF features
   - Train **Naive Bayes, Logistic Regression, Linear SVM, and Random Forest**
   - Compare them by accuracy/precision/recall/F1 and automatically select the best one (highest F1)
   - Show a confusion matrix and run predictions on sample messages
   - Save the chosen model as `spam_model.pkl` and the vectorizer as `tfidf_vectorizer.pkl`

You can re-run the notebook any time to retrain — it will overwrite the `.pkl` files, and the Streamlit app will automatically pick up the new model next time it starts.

## Step 4 — Run the Streamlit app
In the same VS Code terminal (with `venv` still active):
```bash
streamlit run app.py
```
This opens the app in your browser at `http://localhost:8501`. Type or paste a message and click **Predict** to see if it's spam or ham.

## Notes
- The dataset is imbalanced (~87% ham / ~13% spam), so model selection uses **F1-score**, not raw accuracy.
- On this dataset, **Linear SVM** typically wins with ~98% accuracy and ~0.92 F1 on spam — but the notebook picks whichever model actually scores best on your run, so this is automatic, not hardcoded.
- To retrain on your own data, just replace `mail_data.csv` (keep the same two columns: `Category`, `Message`) and re-run the notebook.
